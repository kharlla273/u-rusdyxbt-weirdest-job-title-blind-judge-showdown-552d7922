# Weirdest Job Title: Blind Judge Showdown

Entry for the make.fun bounty
`u-rusdyxbt-weirdest-job-title-blind-judge-showdown-552d7922`.

`main.ts` writes a single job title (60 characters at most, nothing else)
to `/output/entry.txt`. The program is deterministic: every run writes
the exact same bytes.

## Entry

> Professional Apologizer for Billionaires' Exes

## Run

```sh
node main.ts
cat /output/entry.txt
```
